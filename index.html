What it actually does

One agent, the whole desk

Devgent doesn't specialize in one file type — it covers the work that usually means switching between five different apps.

📄

Documents & decks

Word documents, styled PowerPoint presentations with real charts, Excel spreadsheets, and formatted PDF reports — built from your content, not a generic template.

⌨️

Writes and runs code

Generates code in any language, then can execute terminal commands or spin up a live local dev server — always with a permission prompt before anything runs.

🧠

Persistent memory

Devgent remembers your project details, preferences, and decisions across sessions, so you're not re-explaining context every time you open it.

📚

Large context window

Hand it whole files, specs, or reference documents — it keeps track of everything in the conversation, not just your last message.

🛡️

You approve every action

Every file write and every terminal command shows a yes/no confirmation before it happens. Nothing touches your machine without a green light from you.

⚙️

Cloud or fully local

Use a free Google Gemini API key for the fastest experience, or point Devgent at a local Ollama model and run everything offline.

No catch, by design

Free because it's actually yours

🔓 Open source, GNU licensed

The full source is public. Read it, audit it, modify it, or fork it — there's no closed backend deciding what Devgent is allowed to do.

  • No telemetry hidden in a compiled binary you can't inspect
  • Community contributions and issues welcome
  • Build it yourself from source if you'd rather not trust a download

🔑 Bring your own key

Devgent has no servers of its own. Your Gemini API key is stored locally in ~/.devgent/config.json and talks directly to Google's API from your machine.

  • Nothing routes through a third-party server
  • Your key never gets bundled into a shared build
  • Prefer zero cloud calls? Run it against local Ollama instead
